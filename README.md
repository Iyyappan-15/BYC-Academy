# BYC Academy – Official Website

> 🎓 My first client project — built for a real tuition centre in Puducherry, India.

---

## 📖 About This Project

This is the official website I built for **BYC Academy**, a tuition centre located in Puducherry, India. The academy has been helping students with their studies since 2014. They needed a clean, professional website to show their courses, their story, and let parents and students contact them easily.

I built this website from scratch using only simple web technologies — no complicated frameworks, no heavy tools. Just HTML, CSS, and JavaScript.

## 📬 Contact Form Setup

The contact form sends messages to **bycacademy001@gmail.com** using **Google Apps Script**.

This is the most secure way for a static website — no API keys are stored in the code. A Google Apps Script runs on Google's own servers and delivers the email for free, forever.

To activate the form:
1. Go to [https://script.google.com](https://script.google.com)
2. Create a new project with the email script (see `main.js` comments)
3. Deploy it as a Web App
4. Paste the Web App URL inside `main.js` where it says `PASTE_YOUR_GOOGLE_APPS_SCRIPT_URL_HERE`
